## 💼 프로젝트

### 🤖 AI 기반 개발자 모의 면접 시뮬레이터 - DevView  
> **Gemini & 앨런 AI 기반 AI 면접 플랫폼**  
> 취업 준비생을 위한 맞춤 질문 생성 · AI 피드백 · 커뮤니티 · 랭킹 기능 제공  

**📌 담당 역할**  
- **커뮤니티 기능 전체 구현**
  - 게시글/댓글/좋아요/스크랩 CRUD  
  - User와 연관관계 매핑 → 게시글/댓글 작성자 정보 함께 조회  
  - 카테고리/난이도/키워드 기반 **검색 & 필터링** API 구현  
  - 페이징 및 정렬 지원(Spring Data JPA + Specification)  
- **데이터베이스 관리**
  - 프로젝트 **ERD 설계 및 마이그레이션(Flyway)** 담당  
  - User 중심으로 Community, Ranking, InterviewResults 연계 구조 설계  
  - 팀 협업 시 버전 충돌 방지를 위한 DB 규칙 정립  
- **발표**
  - 프로젝트 **최종 발표 준비 및 발표 진행**  
  - 커뮤니티 기능 + DB 설계 파트 소개 및 시연  

**📊 주요 성과**  
- 단순 CRUD를 넘은 **상호작용 가능한 커뮤니티 모듈** 개발  
- Flyway 기반 **DB 이력 관리 및 협업 효율성 향상**  
- 발표 경험을 통해 기술 내용을 **효과적으로 전달하는 역량 강화**
